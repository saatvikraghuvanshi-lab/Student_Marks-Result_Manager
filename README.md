Managing student marks manually can become confusing when student records need to be added, searched, updated, or compared. Calculating total marks, average marks, and pass or fail status for every student also takes time and can lead to mistakes. The Student Marks and Result Manager is a Java-based console application developed to make these tasks simpler and more organised.
The project allows users to add student records, display all stored students, search for a student using their roll number, update marks, and identify the topper based on total marks. Each student record contains a roll number, name, and marks in three subjects. The program calculates the total and average marks automatically. A student is considered to have passed only if they score at least 40 marks in every subject.
The application is developed using object-oriented programming concepts in Java. It consists of three main classes: Student, StudentManager, and Main. These classes separate student information and calculations, student record management, and user interaction. The program also includes input validation for marks, duplicate roll number checking, and a fixed capacity for storing student records.
Through this project, we applied concepts such as classes and objects, constructors, encapsulation, arrays, methods, conditional statements, loops, and switch-case statements. The project provided practical experience in organising a Java program into multiple classes and developing a menu-driven application.
